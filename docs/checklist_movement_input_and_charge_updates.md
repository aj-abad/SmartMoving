- [x] 26.2 `blit` UV 인자 순서를 수정한다.
- [x] 점프 바가 작은 파란 화살표 `(3,0)`에서 큰 파란 화살표 `(2,0)`로 진행되는지 확인한다.

## 키바인딩

- [x] Prone 키를 기본 `C`로 등록하고 번역을 추가한다.
- [x] Dodge 키를 기본 미지정으로 등록하고 번역을 추가한다.
- [x] Prone hold/toggle 입력을 기존 크롤 상태 계산에 연결한다.

- [x] 상태 패킷 bit 36으로 방향 코드 상위 비트를 동기화한다.
